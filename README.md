# Salon_Website-

A premium, modern website for **Y Zone Men's Parlour**, located Behind SNBP School, Manjari Budruk, Pune.

## Features
- **Modern Responsive Design**: Editorial typography, bespoke warm ivory aesthetic, and fluid mobile/desktop layouts.
- **Interactive WhatsApp Enquiry**: Direct service enquiry message builder.
- **Photo-Led Services & Portfolio**: Filterable gallery with accessible lightbox.
- **Verified Business Details**: Accurate location, operating hours, and customer reviews.

## Tech Stack
- React + Vite
- Tailwind CSS
- Lucide React
- Framer Motion

## Getting Started
```bash
npm install
npm run dev
```
